# 🤖 Telegram-бот для скачивания файлов и плагинов по ссылкам

Бот разработан на **Python** с использованием современного фреймворка **aiogram 3** и базы данных **SQLite** (`aiosqlite`).

---

## ⚡ Особенности

- 🔗 **Постоянные ссылки (Deep Linking)**:
  - Ссылки вида `https://t.me/<username_бота>?start=<code>`.
  - Ссылки бессрочные, по ним может перейти неограниченное количество пользователей.
  - Поддерживаются любые файлы: архивы `.zip`, `.rar`, `.7z`, программы `.exe`, документы, видео, музыка, фото, голосовые сообщения.
- 👑 **Панель администратора (`ADMIN_ID`)**:
  - Доступ строго по `ADMIN_ID` (указан в `.env`).
  - Команда `/admin` для открытия меню управления.
  - Создание ссылок: команда `/create <название>` или через кнопку в меню. После этого бот просит отправить файл.
  - Управление ссылками: просмотр информации, копирование готовой ссылки, замена файла без изменения самой ссылки, редактирование названия и персональной подписи, удаление.
  - Статистика: количество пользователей, созданных ссылок и суммарных скачиваний.
  - ✏️ **Полное редактирование всех сообщений**: через админ-панель можно в один клик изменить любое системное сообщение бота (приветствие, текст ошибки, подпись к файлу и т.д.) с поддержкой HTML-разметки.
- 🔄 **Автоперезапуск при изменении кода**:
  - Скрипт `run.py` следит за изменениями всех `.py` файлов и `.env` через библиотеку `watchdog` и мгновенно перезапускает бота без необходимости перезапускать терминал вручную.

## 🚀 Запуск бота

### Способ 1: Двойным кликом (Windows)
Просто запустите файл `run.bat`.

### Способ 2: Через консоль
```bash
python run.py
```
*(Для обычного запуска без отслеживания изменений можно использовать `python main.py`)*

## 📖 Как пользоваться

### 1. Создание ссылки
1. Отправьте боту команду:
   ```
   /create МойПлагин
   ```
   *(или просто `/create`, после чего бот спросит название)*.
2. Бот попросит отправить файл — отправьте архив, документ, видео или фото.
3. Бот мгновенно сгенерирует уникальную ссылку:
   ```
   https://t.me/<username_бота>?start=abc123xyz
   ```
4. Делитесь этой ссылкой в Telegram-каналах, на сайтах или в личных сообщениях.

### 2. Админ-панель
Отправьте команду `/admin`. Вам будут доступны разделы:
- **➕ Создать ссылку** — создание новой ссылки.
- **📋 Список ссылок** — постраничный просмотр всех ссылок, счетчик скачиваний, удаление, редактирование названия, замена файла.
- **✏️ Редактировать сообщения** — изменение всех текстов бота прямо из Telegram.
- **📊 Статистика** — общие показатели бота.
